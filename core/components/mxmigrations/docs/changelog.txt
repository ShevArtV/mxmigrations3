2.2.0-beta
- Порядок миграций — настройка `order` (allow по умолчанию, strict — опция); status --strict согласован.
- Добавлена аннотация @depends с топологической сортировкой; ошибки и циклы видны в up --dry-run и status --strict.
- Метки новых миграций — по текущему времени в поясе label_timezone (по умолчанию Europe/Moscow), без сдвига в будущее.
- Распознавание переименованных миграций по checksum и @renamed-from: повторное выполнение исключено.
- Команда journal:clean чистит записи журнала без файлов (dry-run, запись по --apply).
- Код возврата 2 при ошибках в up (в том числе --dry-run) и в status --strict.


2.1.0-beta
- Убраны journal_table и lock_name: служебные имена определяются id сайта.
- Добавлена синхронизация нескольких xPDO-схем при создании миграций.
- Добавлена команда model:build для безопасной пересборки metadata после миграции.
- Изменения сторонних моделей сохраняются проектным overlay и переживают обновление пакета.
- Добавлен FileTemplate для проектных шаблонов миграций в отдельных файлах.
