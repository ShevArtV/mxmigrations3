mxMigrations — расширяемый раннер и генератор миграций для MODX Revolution 3.

Пакет не создаёт меню и не меняет сайт при установке. Проект подключает его CLI
через собственный PHP-конфиг, задающий каталог миграций, журнал, lock key и классы
провайдеров проектных рецептов. Полная документация: https://github.com/ShevArtV/mxmigrations3
