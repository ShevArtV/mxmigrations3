mxMigrations — расширяемый раннер и генератор миграций для MODX Revolution 3.

Пакет не создаёт меню и не меняет сайт при установке. Проект подключает его CLI
через собственный PHP-конфиг. Журнал и блокировка определяются идентификатором сайта.
CLI умеет обновлять несколько XML-схем xPDO и собирать модели, не затирая классы с
проектной логикой. Полная документация: https://github.com/ShevArtV/mxmigrations3
